Catálogo

Esta página existe só para provar uma coisa: o widget entra num OPAC que ninguém escreveu para ele, com uma linha de HTML, sem passo de build, e sem que o CSS de vinte anos desta página vaze para dentro dele — ou o contrário.

O botão está no canto inferior direito. A chave da biblioteca é pública; a credencial de sessão fica no servidor e nunca chega a este navegador.

Esta caixa tem estilo próprio, e o widget o ignora.
